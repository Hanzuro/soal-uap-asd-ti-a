1. Deskripsi

Kamu adalah programmer Java yang sebelumnya sudah mengembangkan beberapa program untuk perusahaan ekspedisi X-Press. Temanmu, Randy, baru diterima sebagai kurir spesialis divisi Cash On Delivery. Suatu hari ia datang kalang kabut: aplikasi X-Hub miliknya mengalami bug parah!

X-Hub merekomendasikan jalur terbaik memakai ADT Graph berbobot. Sebagian jalan hanya bisa dilewati satu arah (proyek galian mangkrak, jalur tikus, dan sebagainya), sehingga setiap jalan dicatat per arah. Kurir harus pulang lagi, jadi yang dicari adalah rute titik pengantaran → tujuan → titik pengantaran, dengan jalur pergi dan jalur kembali dihitung sendiri-sendiri.

Sebelum mencari jalur terbaik, sistem wajib menelusuri semua titik yang bisa dijangkau secara BFS.

Tugasmu: perbaiki sistem rekomendasi jalur milik Randy yang malang itu!

2. Definisi

  • Graph berbobot per arah: addAdjList(a, b, w) hanya membuat jalan a → b dengan waktu tempuh w. Jalan dua arah ditulis dua kali (bobot boleh berbeda, misalnya karena tanjakan atau macet). Jalan satu arah ditulis sekali.
  • Jalur pergi adalah jalur a → b dengan total bobot terkecil. Jalur kembali adalah jalur b → a dengan total bobot terkecil. Keduanya dicari terpisah, jadi rutenya bisa berbeda, dan keduanya harus ada.
  • Indeks vertex mengikuti urutan masuk ke graph (urutan input), bukan urutan alfabet. Vertex pertama berindeks 0.
  • BFS dimulai dari vertex berindeks 0, mengikuti arah jalan. Tetangga dikunjungi dari indeks terkecil ke terbesar. Hanya vertex yang terjangkau yang dicetak.
  • Jalur pergi dan jalur kembali pada setiap query dijamin tunggal (tidak ada dua jalur dengan total bobot terkecil yang sama).

3. Operasi yang Harus Dibuat

Kamu mengisi Graph.java dan Queue.java (keduanya diberikan kosong), serta melengkapi bagian TODO pada Main.java. Rancang atributnya sendiri (disarankan adjacency matrix, maksimum 26 vertex). Kelas Graph wajib memiliki kontrak berikut: 

public class Graph {
    public Graph()                               // konstruktor tanpa parameter
    public void addVertex(char a)
    public void addAdjList(char a, b, int bobot)
    public void bestRoute(char a, char b)
    public void bfs()
}
  1. addVertex(char a): menambah vertex a pada indeks size, lalu menaikkan size. Jika graph penuh (26 vertex), vertex tidak ditambahkan.
  2. addAdjList(char a, char b, int bobot): membuat jalan satu arah a → b berbobot bobot. Jika salah satu vertex belum ada, tambahkan dulu dengan addVertex.
  3. bestRoute(char a, char b): mencari jalur pergi a → b dan jalur kembali b → a dengan algoritma Dijkstra berbasis array (tanpa priority queue), lalu mencetak hasilnya satu baris diikuti baris baru. Label Jalur Terbaik dari ... : dicetak oleh Main.
    Kondisi Yang dicetak
    a dan b sama Satu vertex saja, contoh C
    Jalur pergi dan kembali ada Rantai pergi-pulang, titik tujuan ditulis sekali, dipisah -> . Contoh: A -> B -> E -> D -> A
    Salah satunya (atau keduanya) tidak ada Jalur Pergi/Kembali tidak ditemukan!
  4. bfs(): menelusuri graph secara Breadth-First dari indeks 0 memakai Queue buatanmu sendiri.
    1. Tandai vertex berindeks 0 sebagai visited, cetak, lalu masukkan ke queue.
    2. Selama queue belum kosong, ambil satu vertex v1.
    3. Kunjungi semua tetangga v1 yang belum dikunjungi dari indeks terkecil: tandai visited, cetak, masukkan ke queue.
    4. Setelah queue kosong, cetak baris baru dan kembalikan semua visited menjadi false.
    Aturan cetak: vertex pertama tanpa awalan, vertex berikutnya diawali -> , tanpa panah atau spasi di akhir baris.

4. Format Input dan Output

Format Input:

  • Baris 1: tiga bilangan bulat N M Q (jumlah vertex, jumlah jalan, jumlah query).
  • Baris 2: N vertex dipisahkan spasi, sesuai urutan penambahan.
  • Baris 3 sampai M+2: a b bobot, yaitu jalan satu arah dari a ke b.
  • Baris M+3 sampai M+Q+2: a b, yaitu titik pengantaran dan titik tujuan.

Format Output:

  • Baris 1: BFS : diikuti hasil BFS dalam satu baris.
  • Baris 2 sampai Q+1: Jalur Terbaik dari a dan b : diikuti rantai pergi-pulang, atau Jalur Pergi/Kembali tidak ditemukan!.

5. Batasan (Constraints)

  • 1 ≤ N ≤ 26, 0 ≤ M ≤ N(N-1), 1 ≤ Q ≤ 20, bobot 1 ≤ w ≤ 100.
  • Vertex berupa satu huruf kapital dan unik. Tidak ada self-loop maupun jalan ganda untuk pasangan arah yang sama. Semua vertex pada jalan dan query dijamin terdaftar. Query boleh memakai a sama dengan b.
  • Graph belum tentu terhubung.
  • Struktur kelas dipisah ketat menjadi 3 berkas: Graph.java, Queue.java, Main.java.
  • Soal dikerjakan from scratch. Dilarang memakai library bawaan Java seperti ArrayList, LinkedList, HashMap, PriorityQueue, java.util.Stack, java.util.Queue, java.util.Arrays, dan java.util.Collections. java.util.Scanner hanya boleh di Main.java.
  • Pastikan output sesuai spesifikasi spasi (BFS : , -> , tanpa spasi tersisa di akhir baris) agar lulus pengujian VPL.

7. Penjelasan Contoh

Contoh 1 (A B C D E = indeks 0 sampai 4)

  • BFS: A mengunjungi B dan C lebih dulu, lalu D, lalu E.
  • Query A E: pergi A -> B -> D -> E berbobot 9. Kembali E -> D -> C -> A berbobot 12. Rute kembali berbeda dari rute pergi.
  • Query B C: pergi B -> D -> C = 5, kembali C -> A -> B = 6.

Contoh 2 (S A B C D E)

  • S -> A dan S -> C adalah jalan satu arah. D dan E berada di komponen lain sehingga tidak pernah tercetak oleh BFS.
  • Query S B: pergi ada (S -> A -> B = 7), tetapi kembali tidak ada. Hasilnya Jalur Pergi/Kembali tidak ditemukan!.
  • Query S D: kedua komponen tidak terhubung. Query E D: rantainya E -> D -> E.

Contoh 3 (A B C D E)

  • Query A E: jalan langsung A -> E berbobot 10 kalah dari A -> B -> C -> D -> E = 8. Kembali langsung E -> A = 1.
  • Query C C: asal dan tujuan sama, cukup cetak C.
  • Query B E: pergi B -> C -> D -> E = 6, kembali E -> A -> B = 3.
